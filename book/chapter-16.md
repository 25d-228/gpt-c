# Chapter 16 — Inference workspaces and token sampling

Training answers a question about known targets: how much loss did the model incur, and how should each weight change? Generation asks a different question: given the current prefix, which token comes next? The forward mathematics is the same, but its storage lifetime and its caller are different.

A generator does not need to allocate gradients and then promise not to use them. It needs weights, temporary forward storage, requested logits, and a selection rule. This chapter builds that path explicitly. It also establishes a deliberately uncached baseline: every new token is selected after recomputing the complete prefix. There is no persistent key/value history yet.

**Prerequisites:** the complete [Chapter 15 companion](https://25d-228.github.io/gpt-c/media/chapter-15/reference/Makefile), including the model's parameter directory, forward operators, version-1 checkpoints, byte data, and explicit `DlRng`. The forward operators accept borrowed matrices and never retain their pointers. The tied table is one parameter, used for both input lookup and output projection.

**Implementation estimate:** **3.00 hours** for this entire chapter: 2.00 for weight-only ownership/loading, workspace reuse, requested logits, and selection; 1.00 for probability boundaries, regression checks, and the application. Reading and unattended computation are separate. Three linked parts form one chapter: this part implements inference storage and execution; [Part 2](https://25d-228.github.io/gpt-c/chapter-16-part-2.html) implements weight-only loading and sampling; [Part 3](https://25d-228.github.io/gpt-c/chapter-16-part-3.html) supplies generation, integration tests, commands, and observed output.

The [65-file companion](https://25d-228.github.io/gpt-c/media/chapter-16/reference/Makefile) contains all prerequisite code. Eight files are new. Among the previous 57 files, only `include/dl/checkpoint.h`, `src/checkpoint.c`, and the Makefile change. The model, optimizer, training tape, and numerical kernels remain unchanged. For new files and full replacements, concatenate filename-labeled blocks in order with one blank line between blocks. Part 2 gives exact replacement/insertion instructions for the small extension to `src/checkpoint.c`.

> **Learning objectives**
> Separate immutable weight ownership from training state; derive a forward workspace from live values rather than every saved activation; select output rows without changing their logits; implement stable categorical sampling; preserve explicit random state and binary output; and establish a baseline for later cached decoding.

## Which row predicts the next token?

Use one sequence. Let its current length be $T$, with token IDs $x_0,\ldots,x_{T-1}$. Let $V$ be the vocabulary size, $D$ the model width, $L$ the number of blocks, $F$ the feed-forward width, $H_q$ and $H_{kv}$ the query and key/value head counts, and $d=D/H_q$ the head width. Write $K=H_{kv}d$ for the combined key/value width. All these dimensions are positive, with the divisibility rules already enforced by the model configuration.

The final hidden matrix has shape $[T,D]$. If its row $t$ is normalized to $n_t$, the tied embedding table $E[V,D]$ produces

$$
z_{t,v}=\sum_{j=0}^{D-1}n_{t,j}E_{v,j}.
$$

Here $z_{t,v}$ is a **logit**, an unnormalized score for vocabulary ID $v$. During training, row $t$ is compared with the known target $x_{t+1}$. During generation, the **last available row**, $t=T-1$, defines the distribution for the not-yet-selected token at position $T$.

For a three-byte prompt with IDs `[65, 32, 114]`, all three rows participate in the decoder. Row two predicts position three. After selecting, for example, byte ID 101, the next call receives `[65, 32, 114, 101]`, and row three predicts position four. Do not feed a shifted prompt, use row zero repeatedly, or ask the model for the nonexistent row three before appending the first generated byte.

There are no targets or loss in this call. Greedy selection chooses an argmax; sampled selection draws from a distribution. These are distinct decoding policies, as described in the [Transformers generation guide, “Greedy search” and “Sampling”](https://huggingface.co/docs/transformers/generation_strategies). Our implementation below defines its own exact tie, temperature, and random-state contracts instead of calling that library.

## A weight owner that has no gradient fields

The existing `DlModel` owns values **and** gradients. Its optimizer owns moments and an accumulation sum. Constructing those objects merely to obtain their values would preserve much of the training allocation even when backward is never called.

Introduce `DlWeights`. It owns one flat float arena and a directory of borrowed matrix views. `DlWeight` records a name, shape/view, and decay metadata needed to recognize the checkpoint directory; it has no gradient. `DlInference` borrows a ready weight owner and owns only reusable temporary storage.

| Object | Owned storage | Lifetime rule |
| --- | --- | --- |
| `DlWeights` | $P$ weight floats and parameter-view records | Immutable after successful copy/load; outlives every workspace |
| `DlInference` | One layer's scratch arena, positions, frequencies | Reused across all blocks and prefix lengths up to capacity |
| Caller logits | $R V$ logical floats, possibly padded | Independent of both arenas; remains valid after another forward call |
| Sampling state | One `DlRng` and $V$ double probabilities | Separate from weights and the trainer's random state |

Here $P$ is the number of unique parameter values and $R$ the number of requested logit rows. In generation, $R=1$. An arena is owned; its views are not separately freed. Copying a live owner with `=` would duplicate ownership and is forbidden. The assignments at the end of constructors are deliberate transfers from a local candidate that is not destroyed afterward.

Create the complete public header:

```c title="include/dl/inference.h"
#ifndef DL_INFERENCE_H
#define DL_INFERENCE_H

#include "dl/model.h"

typedef struct {
    char name[64];
    DlMatrix value;                  /* Borrow into the single weight arena. */
    int decay;                      /* Format metadata, not an optimizer. */
} DlWeight;

typedef struct {
    DlModelConfig config;
    DlWeight *params;               /* Owns param_count view records. */
    DlTensor arena;                 /* Owns ONLY P weight floats. */
    size_t param_count;
    int ready;                     /* Set only by a successful copy/load. */
} DlWeights;

typedef struct {
    const DlWeights *weights;      /* Stable-address immutable borrow. */
    size_t capacity;                /* Maximum ONE-sequence prefix length. */
    DlTensor arena;                 /* One reusable layer, no backward data. */
    size_t *positions;              /* Owns capacity absolute positions. */
    double *inv_freq;               /* Owns head_dim/2 frequencies. */
} DlInference;

/* Empty {0} owners only. No live owner copies, metadata edits or concurrency.
 * Budgets bound float payloads, not metadata/allocator/stack/process memory.
 * Constructors leave out unchanged on failure. Destroy is repeatable.
 * create allocates an UNREADY directory for the checkpoint loader; it zeros
 * the float payload but does not initialize a usable model. from_model copies
 * values only, never gradients, and commits ready=1 after checking finiteness.
 * After copy/load, weights are immutable. Destroy all borrowing workspaces
 * before their weights. Do not reload, move, or mutate a borrowed weight owner. */
DlStatus dl_weights_create(DlWeights *out, DlModelConfig config,
                           size_t max_float_bytes);
DlStatus dl_weights_from_model(DlWeights *out, const DlModel *model,
                               size_t max_float_bytes);
void dl_weights_destroy(DlWeights *weights);
DlStatus dl_inference_create(DlInference *out, const DlWeights *weights,
                             size_t capacity, size_t max_float_bytes);
void dl_inference_destroy(DlInference *workspace);

/* Full-prefix B=1 baseline, no persistent KV state and no allocations here.
 * ids[length] is a separate live array, 1<=length<=capacity, each ID<V.
 * Compute all hidden prefix rows, but final norm/projection only for rows
 * [first_row, first_row+logits.rows). logits.cols==V; nonempty valid view.
 * Caller owns logits, with canonical base/count metadata. Its ENTIRE owner
 * must differ from both arenas; cross-type metadata/IDs are also disjoint.
 * No targets, loss, gradients, moments, dropout, RNG, or hidden append counter.
 * Invalid arguments/IDs/geometry leave logits unchanged. Later numeric errors
 * can partially write logits; discard the WHOLE result on any failure.
 * Scratch is disposable on failure; a fresh full call safely overwrites it.
 * Logits remain caller-owned and survive the next workspace call. */
DlStatus dl_inference_forward(DlInference *workspace, DlBackend backend,
                              const size_t *ids, size_t length,
                              size_t first_row, DlMatrix logits);

#endif
```

A freshly allocated weight directory has `ready=0`. Zero-filled storage is not evidence that a checkpoint was loaded. Only the complete finite-value copy or successful loader commits `ready=1`; workspace construction rejects an unready owner. The checkpoint reader in Part 2 will use the same constructor.

The parameter order remains exactly the training order: table at index zero, nine entries for each block, then the final scale. Thus

$$
P=VD+L\left(2D^2+2KD+3FD+2D\right)+D.
$$

There is no second $VD$ output-table allocation. The same index-zero matrix is read by embedding lookup and, transposed, by the output projection. The directory's `decay` flag does not allocate or attach an optimizer.

## Construct the directory over one checked allocation

Create `src/inference.c`. Its first pieces destroy only owned storage and place one parameter view. `cursor` is a count of float elements, not bytes. Size arithmetic is checked before forming a view; `dl_matrix_view` also checks it against the actual arena extent.

```c title="src/inference.c"
#include "dl/inference.h"

#include <math.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define RETURN_IF_ERROR(call) do { \
    DlStatus status_ = (call); if (status_ != DL_OK) return status_; \
} while (0)

void dl_weights_destroy(DlWeights *w)
{
    if (w == NULL) return;
    free(w->params);
    dl_tensor_destroy(&w->arena);
    *w = (DlWeights){0};
}

static DlStatus weight_record(DlWeights *w, size_t index, size_t *cursor,
                               const char *name, size_t rows, size_t cols,
                               int decay)
{
    DlWeight *p = &w->params[index];
    size_t count = 0, end = 0;
    RETURN_IF_ERROR(dl_size_mul(rows, cols, &count));
    RETURN_IF_ERROR(dl_size_add(*cursor, count, &end));
    int n = snprintf(p->name, sizeof(p->name), "%s", name);
    if (n < 0 || (size_t)n >= sizeof(p->name)) return DL_RANGE;
    RETURN_IF_ERROR(dl_matrix_view(&w->arena, *cursor, rows, cols, cols, &p->value));
    p->decay = decay;
    *cursor = end;
    return DL_OK;
}
```

The directory builder repeats the established **schema**, not the numerical computation. For a block, query and output matrices are $[D,D]$, key and value matrices $[K,D]$, gate and up matrices $[F,D]$, down $[D,F]$, and each normalization scale $[1,D]$. These names and shapes must match Chapter 12 and the checkpoint writer; the import tests compare the actual stored values as well.

```c title="src/inference.c"
static DlStatus weight_directory(DlWeights *w)
{
    DlModelConfig c = w->config;
    size_t cursor = 0;
    RETURN_IF_ERROR(weight_record(w, 0, &cursor, "token_embedding", c.vocab, c.width, 1));
    size_t kv = c.kv_heads * (c.width / c.query_heads);
    const char *names[] = {"attn_norm", "query", "key", "value", "output",
                           "ffn_norm", "gate", "up", "down"};
    const size_t rows[] = {1, c.width, kv, kv, c.width, 1,
                           c.ffn_width, c.ffn_width, c.width};
    const size_t cols[] = {c.width, c.width, c.width, c.width, c.width,
                           c.width, c.width, c.width, c.ffn_width};
    for (size_t layer = 0; layer < c.layers; ++layer) {
        for (size_t slot = 0; slot < DL_BLOCK_PARAMS; ++slot) {
            char name[64];
            int n = snprintf(name, sizeof(name), "blocks.%zu.%s", layer, names[slot]);
            if (n < 0 || (size_t)n >= sizeof(name)) return DL_RANGE;
            int scale = slot == DL_P_ATTN_NORM || slot == DL_P_FFN_NORM;
            RETURN_IF_ERROR(weight_record(w, 1 + layer * DL_BLOCK_PARAMS + slot,
                &cursor, name, rows[slot], cols[slot], !scale));
        }
    }
    RETURN_IF_ERROR(weight_record(w, w->param_count - 1, &cursor,
                                  "final_norm", 1, c.width, 0));
    return cursor == w->arena.count ? DL_OK : DL_STATE;
}

DlStatus dl_weights_create(DlWeights *out, DlModelConfig config,
                           size_t max_float_bytes)
{
    if (out == NULL || max_float_bytes == 0) return DL_ARGUMENT;
    if (out->params != NULL || out->arena.data != NULL ||
        out->param_count != 0 || out->ready) return DL_STATE;
    DlWeights next = {.config = config};
    size_t count = 0, bytes = 0, directory_bytes = 0;
    RETURN_IF_ERROR(dl_model_config_validate(config, &next.param_count, &count));
    RETURN_IF_ERROR(dl_size_mul(count, sizeof(float), &bytes));
    RETURN_IF_ERROR(dl_size_mul(next.param_count, sizeof(*next.params), &directory_bytes));
    if (bytes > max_float_bytes) return DL_RANGE;
    next.params = malloc(directory_bytes);
    if (next.params == NULL) return DL_ALLOC;
    for (size_t i = 0; i < next.param_count; ++i) next.params[i] = (DlWeight){0};
    DlStatus status = dl_tensor_create(&next.arena, 1, &count);
    if (status == DL_OK) status = weight_directory(&next);
    if (status != DL_OK) { dl_weights_destroy(&next); return status; }
    for (size_t i = 0; i < count; ++i) next.arena.data[i] = 0.0f;
    *out = next;
    return DL_OK;
}
```

`dl_model_config_validate` computes the existing unique parameter count before any allocation. Its conservative overflow checks are reused; calling it does not construct a training model. The float budget covers exactly `count * sizeof(float)`. The view-directory allocation is separate and is also checked for arithmetic overflow.

Every record is initialized before a later step can fail. Therefore `dl_weights_destroy` can clean a partially built candidate. The public destination changes only at `*out = next`. There is no second full-size temporary value array during checkpoint loading: the candidate itself is the eventual immutable weight arena.

For comparisons against a live training model, use an independent copy:

```c title="src/inference.c"
DlStatus dl_weights_from_model(DlWeights *out, const DlModel *model,
                               size_t max_float_bytes)
{
    if (out == NULL || model == NULL || model->params == NULL) return DL_ARGUMENT;
    if (out->params != NULL || out->arena.data != NULL ||
        out->param_count != 0 || out->ready) return DL_STATE;
    DlWeights next = {0};
    RETURN_IF_ERROR(dl_weights_create(&next, model->config, max_float_bytes));
    DlStatus status = DL_OK;
    for (size_t p = 0; p < next.param_count && status == DL_OK; ++p) {
        const DlParameter *source = &model->params[p];
        DlMatrix target = next.params[p].value;
        if (strcmp(source->name, next.params[p].name) != 0 ||
            source->value.shape[0] != target.rows || source->value.shape[1] != target.cols) {
            status = DL_SHAPE;
            break;
        }
        for (size_t i = 0; i < source->value.count; ++i) {
            float value = source->value.data[i];
            if (!isfinite(value)) { status = DL_NUMERIC; break; }
            target.base[target.offset + i] = value;
        }
    }
    if (status != DL_OK) { dl_weights_destroy(&next); return status; }
    next.ready = 1;
    *out = next;
    return DL_OK;
}
```

This routine never copies gradients, consumes random numbers, or changes the source model's revision. It scans each source value for finiteness before committing the new owner. If a late parameter is invalid, earlier copied values exist only in the candidate that gets destroyed. The output remains empty.

The copied weights can outlive the source training model. Conversely, subsequent training changes the source, not the copy. A parity test must compare against the same weight state, not train a step between the copy and the comparison. Normal generation will not construct a source `DlModel` at all: it will use the file loader.

## Reuse storage when its last reader is finished

A training tape retains each block's inputs and activations for its future backward pass. In a forward-only call, a value can be discarded after its final forward consumer. The following schedule uses four $[T,D]$ matrices:

| Operation | Reads | Writes | What can now be reused? |
| --- | --- | --- | --- |
| First RMSNorm | `hidden`, attention scale | `norm` | Nothing yet; residual still needs `hidden` |
| Attention | `norm`, weights, positions | `branch`, attention scratch | `norm` after attention returns |
| First residual | `hidden`, `branch` | `middle` | Old `hidden` and old `branch` |
| Second RMSNorm | `middle`, feed-forward scale | `norm` | Prior normalization contents |
| SwiGLU | `norm`, weights | `branch`, feed-forward scratch | Prior attention result |
| Second residual | `middle`, `branch` | `hidden` | `middle`, `norm`, `branch`, both scratch sets |

Every individual kernel still has distinct inputs and outputs. This is **lifetime-based reuse between calls**, not an unsupported in-place RMSNorm or matrix multiplication. In particular, the first residual must finish before the old `hidden` may be overwritten.

The existing `DlAttentionCache` type is reused as transient forward storage. Its name does not turn it into a decoding cache: it is overwritten for every block, contains only this call's prefix, and is not extended or committed across tokens. Scores and probabilities are still materialized. The three feed-forward arrays also remain, avoiding a change to the already-tested SwiGLU operator.

Count the live float payload at capacity $C$:

$$
A_{\mathrm{infer}}(C)=7CD+3CK+3CF+2H_qC^2.
$$

The four outer matrices contribute $4CD$. Attention contributes three more width-$D$ matrices (`q0`, `q`, `context`), three width-$K$ matrices (`k0`, `v`, `k`), and two score-sized matrices. Feed-forward scratch contributes $3CF$. **There is no factor of $L$.** There is still a quadratic term in capacity.

For $T=3$, $D=8$, $K=4$, $F=12$, and $H_q=4$, a single call needs 384 floats. These are the exclusive element ranges:

| Views, in allocation order | Float-element range |
| --- | --- |
| `hidden`, `norm`, `branch`, `middle` | `[0,24)`, `[24,48)`, `[48,72)`, `[72,96)` |
| `q0`, `k0`, `v`, `q`, `k` | `[96,120)`, `[120,132)`, `[132,144)`, `[144,168)`, `[168,180)` |
| `scores`, `probs`, `context` | `[180,216)`, `[216,252)`, `[252,276)` |
| gate, value, hidden feed-forward arrays | `[276,312)`, `[312,348)`, `[348,384)` |

Each score view has $H_qT=12$ rows and $T=3$ columns. All views retain the canonical arena base and its **full allocated count**. A shortened prefix changes view offsets and shapes, not the allocation. Unused capacity is not initialized or read by a successful forward pass.

## Count first, map second

The private `Views` aggregate contains only borrowed descriptors. `layout` executes the same placement logic both when the arena is empty, to count capacity, and when it is allocated, to build the current prefix views. Its `PLACE` macro simply invokes `place` and propagates a status; it is not a hidden allocator.

```c title="src/inference.c"
typedef struct {
    DlMatrix hidden, norm, branch, middle;
    DlAttentionCache attention;
    DlFfnCache ffn;
} Views;

static DlStatus place(DlTensor *arena, size_t *cursor, size_t rows, size_t cols,
                       DlMatrix *view)
{
    size_t count = 0, end = 0;
    RETURN_IF_ERROR(dl_size_mul(rows, cols, &count));
    RETURN_IF_ERROR(dl_size_add(*cursor, count, &end));
    if (arena->data != NULL)
        RETURN_IF_ERROR(dl_matrix_view(arena, *cursor, rows, cols, cols, view));
    *cursor = end;
    return DL_OK;
}

static DlStatus layout(DlTensor *arena, DlModelConfig c, size_t time,
                        Views *v, size_t *count)
{
    size_t cursor = 0, score_rows = 0;
    size_t kv = c.kv_heads * (c.width / c.query_heads);
    RETURN_IF_ERROR(dl_size_mul(time, c.query_heads, &score_rows));
#define PLACE(rows_, cols_, member_) \
    RETURN_IF_ERROR(place(arena, &cursor, rows_, cols_, &v->member_))
    PLACE(time, c.width, hidden);
    PLACE(time, c.width, norm);
    PLACE(time, c.width, branch);
    PLACE(time, c.width, middle);
    PLACE(time, c.width, attention.q0);
    PLACE(time, kv, attention.k0);
    PLACE(time, kv, attention.v);
    PLACE(time, c.width, attention.q);
    PLACE(time, kv, attention.k);
    PLACE(score_rows, time, attention.scores);
    PLACE(score_rows, time, attention.probs);
    PLACE(time, c.width, attention.context);
    PLACE(time, c.ffn_width, ffn.gate);
    PLACE(time, c.ffn_width, ffn.value);
    PLACE(time, c.ffn_width, ffn.hidden);
#undef PLACE
    *count = cursor;
    return DL_OK;
}
```

The initial capacity layout checks every product and addition. Since each term grows monotonically with the positive prefix length, a later length no greater than capacity fits. The second layout still calls `dl_matrix_view` for each range, so an incorrect future edit is not silently trusted.

Allocate the two metadata arrays separately. Positions are the absolute indices $0,1,\ldots,C-1$ for this one sequence. The fixed frequency table has $d/2$ doubles. Neither is a mutable append counter.

```c title="src/inference.c"
void dl_inference_destroy(DlInference *s)
{
    if (s == NULL) return;
    free(s->inv_freq);
    free(s->positions);
    dl_tensor_destroy(&s->arena);
    *s = (DlInference){0};
}

DlStatus dl_inference_create(DlInference *out, const DlWeights *weights,
                             size_t capacity, size_t max_float_bytes)
{
    if (out == NULL || weights == NULL || weights->params == NULL ||
        capacity == 0 || max_float_bytes == 0) return DL_ARGUMENT;
    if (!weights->ready) return DL_STATE;
    if (out->weights != NULL || out->arena.data != NULL ||
        out->positions != NULL || out->inv_freq != NULL || out->capacity != 0)
        return DL_STATE;
    if (capacity - 1 > DL_ROPE_MAX_POSITION) return DL_RANGE;
    DlInference next = {.weights = weights, .capacity = capacity};
    Views views = {0};
    size_t count = 0, bytes = 0, position_bytes = 0, frequency_bytes = 0;
    size_t frequencies = weights->config.width / weights->config.query_heads / 2;
    RETURN_IF_ERROR(layout(&next.arena, weights->config, capacity, &views, &count));
    RETURN_IF_ERROR(dl_size_mul(count, sizeof(float), &bytes));
    RETURN_IF_ERROR(dl_size_mul(capacity, sizeof(*next.positions), &position_bytes));
    RETURN_IF_ERROR(dl_size_mul(frequencies, sizeof(*next.inv_freq), &frequency_bytes));
    if (bytes > max_float_bytes) return DL_RANGE;
    DlStatus status = dl_tensor_create(&next.arena, 1, &count);
    if (status == DL_OK) {
        next.positions = malloc(position_bytes);
        next.inv_freq = malloc(frequency_bytes);
        if (next.positions == NULL || next.inv_freq == NULL) status = DL_ALLOC;
    }
    if (status == DL_OK) {
        for (size_t i = 0; i < capacity; ++i) next.positions[i] = i;
        status = dl_rope_frequencies(weights->config.width / weights->config.query_heads,
                                     weights->config.rope_theta, next.inv_freq, frequencies);
    }
    if (status != DL_OK) { dl_inference_destroy(&next); return status; }
    *out = next;
    return DL_OK;
}
```

The workspace takes a stable-address borrow of `weights`, so destroy it first. Failure after the float arena or either metadata allocation releases every successfully acquired object. A failed constructor leaves the caller's empty destination unchanged. `capacity=0` is invalid; the existing RoPE position bound and checked arithmetic prevent oversized placement before a forward call begins.

The formula counts only float payload. Add $C\,\mathrm{sizeof(size\_t)}$ for positions, $(d/2)\,\mathrm{sizeof(double)}$ for frequencies, owner/view records, caller arrays, and the matrix backend's bounded stack scratch when estimating live allocations. Allocator and library overhead still prevent this sum from being a process resident-memory measurement.

## Project only the requested rows

For any contiguous requested range starting at row $r$ and containing $R$ rows, require

$$
0\le r<T,\qquad 1\le R\le T-r.
$$

The subtraction form avoids an unchecked `r + R`. Every block still processes the entire prefix. Only **after the last block** may we restrict the final normalization and vocabulary projection to those rows: RMSNorm acts independently on rows, and the projection has no cross-row dependency.

The selected hidden view starts at element offset `hidden.offset + r * hidden.ld`; its base and allocation count are unchanged. Normalize those $R$ rows into the first $R$ rows of `norm`, then compute $[R,D][D,V]\to[R,V]$. Computing a last row is not equivalent to running every layer on only the last input token; that would remove its attention context.

```c title="src/inference.c"
static DlConstMatrix weight(const DlWeights *w, size_t index)
{
    return dl_matrix_read(w->params[index].value);
}

DlStatus dl_inference_forward(DlInference *s, DlBackend backend,
                              const size_t *ids, size_t length,
                              size_t first_row, DlMatrix logits)
{
    if (s == NULL || s->weights == NULL || s->arena.data == NULL || ids == NULL)
        return DL_ARGUMENT;
    if (backend != DL_BACKEND_REF && backend != DL_BACKEND_BLOCKED) return DL_ARGUMENT;
    const DlWeights *w = s->weights;
    if (!w->ready) return DL_STATE;
    DlModelConfig c = w->config;
    if (length == 0 || length > s->capacity || first_row >= length) return DL_RANGE;
    size_t end = 0;
    RETURN_IF_ERROR(dl_matrix_end(dl_matrix_read(logits), &end));
    if (logits.cols != c.vocab || logits.rows > length - first_row) return DL_SHAPE;
    if (logits.base == s->arena.data || logits.base == w->arena.data) return DL_ALIAS;
    for (size_t i = 0; i < length; ++i) if (ids[i] >= c.vocab) return DL_RANGE;
    Views v = {0};
    size_t count = 0;
    RETURN_IF_ERROR(layout(&s->arena, c, length, &v, &count));
    DlAttentionConfig a = {1, length, c.query_heads, c.kv_heads, c.width / c.query_heads};
    RETURN_IF_ERROR(dl_embedding_forward(weight(w, 0), ids, length, v.hidden));
    for (size_t layer = 0; layer < c.layers; ++layer) {
        size_t base = 1 + layer * DL_BLOCK_PARAMS;
        DlAttentionWeights aw = {weight(w, base + DL_P_QUERY), weight(w, base + DL_P_KEY),
            weight(w, base + DL_P_VALUE), weight(w, base + DL_P_OUTPUT)};
        DlFfnWeights fw = {weight(w, base + DL_P_GATE), weight(w, base + DL_P_UP),
                           weight(w, base + DL_P_DOWN)};
        RETURN_IF_ERROR(dl_rmsnorm_forward(dl_matrix_read(v.hidden),
            weight(w, base + DL_P_ATTN_NORM), c.epsilon, v.norm));
        RETURN_IF_ERROR(dl_attention_forward(backend, a, dl_matrix_read(v.norm), aw,
            s->positions, length, s->inv_freq, a.head_dim / 2, v.attention, v.branch));
        RETURN_IF_ERROR(dl_residual_add(dl_matrix_read(v.hidden), dl_matrix_read(v.branch), v.middle));
        RETURN_IF_ERROR(dl_rmsnorm_forward(dl_matrix_read(v.middle),
            weight(w, base + DL_P_FFN_NORM), c.epsilon, v.norm));
        RETURN_IF_ERROR(dl_ffn_forward(backend, dl_matrix_read(v.norm), fw, v.ffn, v.branch));
        RETURN_IF_ERROR(dl_residual_add(dl_matrix_read(v.middle), dl_matrix_read(v.branch), v.hidden));
    }
    DlMatrix selected = v.hidden;
    selected.offset += first_row * selected.ld; /* Bounded by length above. */
    selected.rows = logits.rows;
    DlMatrix norm = v.norm;
    norm.rows = logits.rows;
    RETURN_IF_ERROR(dl_rmsnorm_forward(dl_matrix_read(selected),
        weight(w, w->param_count - 1), c.epsilon, norm));
    return dl_matmul(backend, dl_matrix_read(norm), DL_NOTRANS,
                     weight(w, 0), DL_TRANS, logits, DL_SET);
}

#undef RETURN_IF_ERROR
```

The forward function performs no heap allocation, loss evaluation, gradient clearing, optimizer update, or random draw. It recomputes positions from the same initialized prefix array every call. The last projection reads `weight(w, 0)`, preserving the tied-table orientation.

The final output is caller-owned. A whole-prefix result can therefore be retained while another call produces a last-row result for comparison. This also avoids keeping a mandatory $[C,V]$ output allocation inside the workspace. The alias guard conservatively rejects **any** output view whose canonical owner is either arena, even a seemingly unused subrange. Cross-type overlap with IDs or metadata remains a caller prohibition; C cannot discover whether a fabricated pointer truly refers to its declared allocation.

Structural failures, out-of-range IDs, and invalid selections are found before numerical work. Numerical failures may leave scratch partially written; a failure in the final matrix product may also leave some output logits written. Discard the entire result on any non-`DL_OK` status. A fresh full-prefix call overwrites its required scratch, so it can recover after the cause is removed without consuming stale partial state. There is no committed prefix to roll back yet.

The old training tape and every derivative implementation remain intact. In Part 3, parity tests deliberately leave a training tape ready, run several inference calls, and then successfully differentiate the original tape. That separates an implementation that genuinely owns independent forward storage from one that merely borrows and mutates the training tape.
